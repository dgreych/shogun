# Segurança

O SHOGUN opera com uma sessão real do WhatsApp. Cuide dela como cuidaria do próprio aparelho.

- use um número dedicado quando possível;
- mantenha `dados/database/qr-code/`, `dados/src/config.json` e `.env.local` fora de compartilhamentos;
- nunca envie QR, código de pareamento ou arquivo de sessão a terceiros;
- não publique bancos, logs ou mídias de grupos reais;
- conceda administração apenas onde as funções administrativas forem necessárias;
- faça backup local criptografado antes de atualizar uma instalação importante;
- remova o aparelho conectado pelo próprio WhatsApp se suspeitar de acesso indevido;
- use automações com consentimento e respeite a privacidade das pessoas.

O repositório ignora os arquivos locais mais sensíveis, mas essa proteção não substitui cuidado ao compactar pastas ou enviar diagnósticos.
