# Mídia do 𝖘𝖍𝖔𝖌𝖚𝖓

Arquivos servidos ao bot em tempo de execução: vídeos das brincadeiras e
figurinhas do sorteio.

Ficam numa branch separada de propósito. O download do código-fonte pega a
`main`, e mídia pesada ali dentro tornaria esse download inviável.

```
brincadeiras/<comando>.mp4
figurinhas/fig-<n>.webp
```
